# Handy-Menü-Controller

The Handy-Menü-Controller is a Minecraft plugin that provides a customizable smartphone GUI for players. It allows players to interact with a smartphone interface in-game, featuring various apps and control elements. The plugin uses the PaperMC API for enhanced functionality and includes features like customizable colors, animations, and sound effects.

## Install

1. Download the plugin JAR file from the releases section.
2. Place the JAR file in the `plugins` folder of your Minecraft server.
3. Restart the server to load the plugin.

## Use

1. Join the Minecraft server where the plugin is installed.
2. Use the command `/ciao` to interact with the plugin and receive a greeting message.
3. The smartphone GUI will be automatically created and can be accessed by the player.
